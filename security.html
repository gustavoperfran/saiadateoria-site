Privacy and security

How we protect your data.

We use technical and operational controls across the application, API and database. Access is limited to what is required to run the service.

Our approachMinimise data.Limit access.Protect every connection.
01

Encrypted in transit

Traffic between your browser, our application and infrastructure providers is protected with HTTPS/TLS.

02

Access is limited

Role-based controls and tenant isolation restrict access to what is required to operate the service.

03

Credentials stay private

Sensitive service credentials remain server-side. We never request or store online-banking passwords.

How protection works

Practical controls across the platform.

Saia da Teoria is operated by GPF IT SOLUTIONS PTY LTD (ABN 57 638 578 140). Our controls evolve with the product and its regulatory obligations.

01

Authentication and sessions

User authentication is provided through Supabase Auth. Application access tokens are kept in memory rather than long-term browser storage. Sessions expire, and inactive sessions are automatically ended.

02

Workspace isolation

Each customer workspace is isolated by tenant identifiers in the API and database. Database Row Level Security provides an additional control. Authorised support access is read-only where possible, role-restricted and recorded.

03

Bank connectivity

Bank connectivity is being prepared using Basiq’s hosted consent experience. API credentials remain on the server, webhook signatures are verified, and only approved data scopes required for balances and transactions are requested.

04

Data minimisation and monitoring

We aim to collect only the information required for requested features. Security-relevant access and operational events are logged to support investigation and incident response.

Responsible reporting

Report a security issue.

Email contact@saiadateoria.com. Do not include passwords, bank credentials or unnecessary personal information. We will acknowledge credible reports and investigate them promptly.
