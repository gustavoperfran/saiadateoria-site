Security

How we protect Saia da Teoria

Security by design

Saia da Teoria is operated by GPF IT SOLUTIONS PTY LTD (ABN 57 638 578 140). Security controls are applied across the application, API and data layers, with access limited to what is required to operate the service.

Encryption

Traffic between browsers, application services and infrastructure providers is encrypted using HTTPS/TLS. Sensitive service credentials are stored server-side and are not embedded in the browser application.

Authentication and sessions

User authentication is provided through Supabase Auth. Application access tokens are kept in memory rather than long-term browser storage, sessions expire, and inactive sessions are automatically ended.

Tenant isolation and access

Each customer workspace is isolated by tenant identifiers in the API and database. Database Row Level Security provides an additional control. Authorised support access is read-only where possible, restricted by role and recorded.

Bank connectivity

Bank connectivity is being prepared using Basiq’s hosted consent experience. We do not request or store online-banking passwords. API credentials remain on the server, webhook signatures are verified, and only the approved data scopes needed for balances and transactions are requested.

Data minimisation and monitoring

We aim to collect only the information required for requested features. Security-relevant access and operational events are logged to support investigation and incident response.

Responsible reporting

If you believe you have found a security issue, email contact@saiadateoria.com. Do not include passwords, bank credentials or unnecessary personal information. We will acknowledge credible reports and investigate them promptly.

Important limitation

No online service can guarantee absolute security. We continually review controls as the product and its regulatory obligations evolve.
